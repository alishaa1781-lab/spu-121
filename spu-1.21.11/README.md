# spu-1.21.11 (FT helper)

Клиентский Fabric-мод для Minecraft 1.21.11.

## Как работает

- **J** открывает click GUI. В нём для каждого предмета можно назначить бинд и включить или выключить его.
- По нажатию бинда мод:
  1. полностью останавливает игрока, если он двигался;
  2. меняет местами предмет из инвентаря и **слот 1**, выбирает слот 1;
  3. нажимает **ПКМ**;
  4. возвращает всё обратно: то, что лежало в слоте 1, снова на месте, предмет на своём месте, выбранный слот прежний;
  5. снимает блокировку, и если клавиши движения всё ещё зажаты, игрок продолжает идти.
- Между шагами задержка 200 мс.

## Предметы

| Предмет Minecraft | Название |
|---|---|
| Снежок | Снежок заморозки |
| Незеритовый лом | Трапка |
| Око Эндера | Дезориентация |
| Сушёная ламинария | Пласт |
| Сахар | Явная пыль |
| Огненный шар | Огненный шар |

Предмет ищется по типу, сначала в слоте 1, потом в остальной панели и основном инвентаре.

## GUI

- ЛКМ по кнопке бинда: назначить, затем нажать клавишу или боковую кнопку мыши (3 и выше).
- ESC: отмена назначения. ПКМ по кнопке или DELETE: убрать бинд.
- Зелёный квадрат: предмет включён.
- Настройки сохраняются в `config/spu.json`. Там же можно поменять `delayMs` (по умолчанию 200).

## Сборка

Нужна Java 21. Сборка: `./gradlew build`. Готовый jar: `build/libs/spu-1.21.11.jar` (кладётся в папку `mods` вместе с Fabric API 0.141.6+1.21.11).
Запуск для теста из IDE: `./gradlew runClient`.
